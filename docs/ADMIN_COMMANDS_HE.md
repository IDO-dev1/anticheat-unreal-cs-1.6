# פקודות אדמין

הפקודות מופעלות מקונסולת השרת או באמצעות RCON:

- `liveac_help` — הצגת עזרה.
- `liveac_status` — רשימת שחקנים פעילים והציון שלהם.
- `liveac_status 4` — פרטים על שחקן בסלוט 4.
- `liveac_status partOfName` — חיפוש לפי חלק מהשם.
- `liveac_reset 4` — איפוס ציון וראיות לשחקן.
- `liveac_reset all` — איפוס כל השחקנים.

פקודות אלה אינן פקודות צ'אט ואינן תלויות ב-AMXX. השתמש בהן בקונסולת השרת או דרך RCON.
