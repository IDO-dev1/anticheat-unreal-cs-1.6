# v0.7 — הוראות בדיקה

1. הוסף את SteamID של האדמין אל `addons/liveac/liveac_admins.ini`.
2. טען מחדש: `liveac_reload_admins`.
3. התחל סריקה פרטית: `liveac_scan IDO 60`.
4. הדוח יופיע רק בקונסולה של האדמין שהפעיל את הבדיקה.
5. אירועי הפאנל נמצאים ב־`addons/liveac/logs/panel_events.jsonl`.
6. בדוק `liveac_status IDO` ו־`liveac_top` לציונים שוטפים.

אין Ban/Kick אוטומטי בגרסה זו.
