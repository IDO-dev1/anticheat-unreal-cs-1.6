# v0.8 — בדיקה מאומתת לפי כמות דגימות

הרץ:

```text
liveac_scan IDO 120
```

הדוח מפריד בין ארבע קבוצות:

- AIM: דורש לפחות 8 רכישות מטרה ו־80 דגימות נראות.
- FIRE: דורש לפחות 20 לחיצות ירי ו־5 יריות כשהאויב נראה.
- MOVEMENT: דורש לפחות 8 נחיתות ו־8 קפיצות.
- SPEED: דורש לפחות 300 דגימות תנועה.

`INSUFFICIENT` אינו `PASS`; יש להאריך את הסריקה או לבצע יותר פעולות רלוונטיות.

הדוח הפרטי נשלח רק לאדמין שהפעיל את הסריקה. סיכום JSON נכתב לפאנל.
